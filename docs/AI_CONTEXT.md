# 换装相机 AI Context

This document provides context for AI assistants working on the 换装相机 project.

## Project Goal
换装相机 is a tool that takes a user's room photo and uses AI to generate a redesigned version of that room, complete with a shoppable list of furniture and decor.

## Tech Stack
- **Backend:** Python, FastAPI, Loguru (logging)
- **Frontend:** WeChat Mini Program (WXML, WXSS, JS)
- **AI Models:**
  - Vision LLM (e.g., Qwen-VL via API) for image analysis, prompt generation, and item identification.
  - Image Generation Model (e.g., Seedream via API) for rendering the new room.
- **Storage:** Tencent Cloud COS (optional, falls back to local storage).

## Key Concepts & Terminology
- **V2 Workflow (`/v2/transform`):** The current primary workflow. It's designed for speed by running prompt generation/item identification concurrently with image generation.
- **Task Polling:** The frontend doesn't wait for the entire generation process to finish in one request. It starts a task and then polls `/task/{task_id}` for status updates.
- **Typewriter Effect:** The design description generated by the LLM is streamed to the frontend and displayed character-by-character to keep the user engaged while the image is generating.

## Important Files to Know
- `backend/api/routes.py`: The entry point for all API requests. Look here for how tasks are started and polled.
- `backend/services/image_generator.py`: Contains the complex logic for orchestrating the LLM and image generation models, particularly `generate_v2_with_items`.
- `backend/models/schemas.py`: Defines the Pydantic models used for API requests and responses. Crucial for understanding data structures.

## Common Tasks for AI Assistants
- **Adding a new style or room type:** Update `backend/services/prompts_i18n.py` and the corresponding enums in `backend/models/schemas.py`.
- **Modifying the LLM prompt:** Look in `backend/services/image_generator.py` (specifically the `_generate_vllm_prompt_and_items` method).
- **Debugging generation failures:** Check the logs for errors from the VLLM or Seedream APIs in `image_generator.py`.
