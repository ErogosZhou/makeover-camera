# 流式加载体验优化实施说明

## 🎯 核心设计理念

**从"告诉用户还要等多久"到"让用户感觉一直在产出"**

### 优化前 ❌
```

[进度条: ████░░░░░░ 40%]
```
- 用户盯着进度条焦虑
- 被动等待
- 感觉时间很慢

### 优化后 ✅
```

匹配风格和色彩方案

✓ 藤编吊灯
✓ 亚麻窗帘
✓ 原木茶几
[持续流式显示...]
```
- 持续看到新产出
- 主动参与感
- 感觉时间飞逝

## 🚀 实现的三大核心功能

### 1. 情境化过程提示

**移除了**：预估时间（"预计 25 秒"）

**改为**：情境化文案
```javascript
// 不同阶段的文案
'pending'     → '正在准备创作...' + '分析空间特征'
'generating'  → 'AI 正在绘制效果图...' + '匹配风格和色彩方案'
'identifying' → '正在识别软装物品...' + '逐个分析家具和装饰'
'matching'    → '正在为你寻找商品...' + '从海量商品中精选匹配'
```

**心理学原理**：透明度悖论 - 知道"正在做什么"比"还需多久"更能缓解焦虑

---

### 2. 流式显示识别物品

**效果**：识别到一个物品就立即显示一个

```html
<!-- 动态流式添加 -->
<div class="streaming-items">
  ✓ 藤编吊灯       [滑入动画]
  ✓ 亚麻窗帘       [滑入动画]
  ✓ 原木茶几       [滑入动画]
  ...
</div>
```

**实现逻辑**：
```javascript
// 轮询时检测新物品
if (data.status === 'identifying' && data.result?.shopping_list) {
    const newItems = data.result.shopping_list.map(item => item.identified_item);
    newItems.forEach(newItem => {
        if (!this.streamingItems.find(item => item.id === newItem.id)) {
            this.streamingItems.push(newItem);  // 流式添加
        }
    });
}
```

**心理学原理**：Zeigarnik效应 - 持续的小"奖励"维持注意力

---

### 3. 渐进式图片加载

**效果**：图片从模糊到清晰，模拟 AI 绘制过程

```
阶段1: 显示模糊图片 (blur-sm)
   ↓ [扫描线动画从上到下]
阶段2: 图片逐渐清晰 (blur-0)
```

**实现方式**：
```html
<img :src="generatedImageUrl"
     :class="{ 'blur-sm': imageLoading, 'blur-0': !imageLoading }"
     @load="imageLoading = false">

<!-- 扫描线效果 -->
<div x-show="imageLoading" class="animate-scan"></div>
```

**CSS 动画**：
```css
@keyframes scan {
    0% { top: 0; opacity: 0.8; }
    100% { top: 100%; opacity: 0; }
}

.transition-all {
    transition: all 1000ms;  /* 1秒淡入 */
}
```

**心理学原理**：完形心理学 - 大脑会自动"补完"不完整的图像，产生参与感

## 🎓 心理学原理总结

### 1. Zeigarnik 效应
- **原理**：未完成的任务比已完成的更吸引注意力
- **应用**：流式显示物品，持续有新内容出现

### 2. 透明度悖论
- **原理**：了解系统在做什么比知道还需多久更能缓解焦虑
- **应用**：情境化文案（"正在识别家具"而非"还需20秒"）

### 3. 操作性条件反射
- **原理**：持续的小奖励维持多巴胺分泌
- **应用**：每个新物品都是一次"奖励"

### 4. 完形心理学
- **原理**：大脑会自动"补完"不完整的图像
- **应用**：模糊到清晰的图片加载，让用户参与"创作"

### 5. 峰值-终值法则
- **原理**：体验的高峰和结束时刻影响整体评价
- **应用**：
  - 高峰：流式物品快速出现
  - 终值：完整清晰的效果图
